#Extreme Writer

A distraction-free writing application for Windows, inspired by Cold Turkey Writer.
The goal of this project is to create a writing environment where the user can focus entirely on writing without easily accessing distracting applications or system functions.

##Currently implemented

-Fullscreen writing interface
-Distraction-free text editor
-Word counter
-Line wrapping
-Prevents normal window closing
-Built with Java Swing
-Planned
-Scheduled writing sessions
-Automatic lock activation based on the current time
-Persistent sessions when the computer is restarted
-Windows-level keyboard restrictions
-Prevention of common ways to leave the writing environment
-Automatic unlock when the scheduled session ends
-Automatic saving / recovery of writing sessions

##Why?
This project was created for personal focus and self-discipline.
The idea is simple:
When it's time to write, the computer becomes a typewriter.
Instead of relying only on motivation, the application is intended to create an environment where distractions are difficult to access during a writing session.
